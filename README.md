# فروشگاه استودیو اورل

فروشگاه اینترنتی راست‌چین فارسی برای شال، روسری، پوشاک و اکسسوری، همراه با صفحه‌ی جزئیات هر محصول و پنل مدیریت. نسخه‌ی نمایشی با داده‌های نمونه اجرا می‌شود؛ با اتصال Supabase، فهرست محصولات، سفارش‌ها و مدیریت فروشگاه به پایگاه داده‌ی زنده متصل خواهند شد.

## اجرای محلی

از این پوشه یک وب‌سرور ایستا اجرا کنید؛ برای نمونه:

```sh
npx serve .
```

محصولات، قیمت‌ها و سفارش‌های نمایشی در مرورگر ذخیره می‌شوند. روی نماد ↗ در سربرگ بزنید تا پنل مدیریت را ببینید. قیمت‌های نمونه‌ی تومان صرفاً نمونه هستند و می‌توانید پیش از راه‌اندازی فروشگاه، آن‌ها را در پنل یا فایل seed تغییر دهید.

## اتصال Supabase

1. یک پروژه‌ی Supabase بسازید.
2. فایل `supabase/schema.sql` و سپس `supabase/seed.sql` را در SQL Editor اجرا کنید.
3. نشانی پروژه و کلید عمومی anon را از بخش تنظیمات API بردارید و در `config.js` قرار دهید.
4. در بخش Authentication یک حساب مدیر بسازید. شناسه‌ی کاربر را بردارید و دستور SQL توضیح‌داده‌شده در انتهای `supabase/seed.sql` را اجرا کنید.
5. سایت را روی یک وب‌سرور ایستا یا GitHub Pages منتشر کنید.

در تنظیمات مرورگر فقط از کلید عمومی anon استفاده کنید؛ کلید service_role را هرگز در سایت قرار ندهید. سیاست‌های RLS اطلاعات مدیریت را محدود می‌کنند. ثبت سفارش در دیتابیس مبلغ را بر اساس قیمت و موجودی همان لحظه محاسبه می‌کند. پرداخت آنلاین هنوز متصل نیست و سفارش‌ها برای پیگیری دستی ثبت می‌شوند.

## امکانات پنل مدیریت

- نمای کلی فروش، سفارش‌ها، محصولات فعال و موجودی کم
- افزودن، ویرایش و حذف محصول، قیمت‌گذاری به تومان، تصویر و موجودی
- جست‌وجو و تغییر وضعیت سفارش‌ها
- گزارش موجودی، کالاهای ناموجود و ارزش موجودی انبار
- فروشگاه واکنش‌گرا با جست‌وجو، فیلتر، مرتب‌سازی، سبد خرید و صفحه‌ی مستقل هر محصول
